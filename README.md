# Сайт-визитка — Цветков Павел

Стек: Vite + React + React Router (HashRouter) + Framer Motion (переходы
между страницами) + Embla Carousel (портфолио).

Весь текстовый контент вынесен в один файл — `src/data/content.js`.
Чтобы поправить текст, опыт, портфолио или контакты, редактируйте только
этот файл, вёрстку трогать не нужно.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Статика соберётся в папку `dist/`.

## Деплой на GitHub Pages

### Вариант 1 — через пакет gh-pages (проще всего)

1. Создайте репозиторий на GitHub, запушьте туда этот проект.
2. Установите зависимости (`gh-pages` уже в devDependencies):
   ```bash
   npm install
   ```
3. Выполните:
   ```bash
   npm run deploy
   ```
   Эта команда соберёт проект и запушит `dist/` в ветку `gh-pages`.
4. В настройках репозитория: **Settings → Pages → Source** выберите ветку
   `gh-pages`, папка `/ (root)`.
5. Сайт будет доступен на `https://<ваш-username>.github.io/<repo-name>/`.

### Вариант 2 — через GitHub Actions

Если хотите, чтобы сайт пересобирался автоматически при каждом пуше —
создайте `.github/workflows/deploy.yml` со стандартным Actions-воркфлоу
для Vite (`actions/deploy-pages`). Могу собрать такой файл отдельно,
если понадобится.

## Важно про base путь

В `vite.config.js` стоит `base: './'` — это значит сборка работает с
любым именем репозитория без дополнительной настройки. Ничего менять не
нужно.

## Структура проекта

```
src/
  data/content.js       — весь текст (резюме, портфолио, контакты)
  components/            — переиспользуемые части (карточки, переходы)
  pages/                 — 4 страницы: Home, Experience, Portfolio, Contact
  App.jsx                — роутинг и навигация
  index.css              — вся дизайн-система (цвета, шрифты, отступы)
```

## Что стоит донастроить

- Ссылки в портфолио (`link` в `content.js`) сейчас ведут на общий GitHub
  профиль — замените на прямые ссылки на конкретные папки/репозитории
  с write-up'ами, когда они появятся.
- Иконка сайта (favicon) не добавлена — можно добавить `favicon.svg` в
  `index.html`.
